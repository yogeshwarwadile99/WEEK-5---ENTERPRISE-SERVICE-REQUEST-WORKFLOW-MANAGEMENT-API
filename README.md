# 🚀 Enterprise Service Request & Workflow Management API

## 📋 Project Overview

A production-style backend system for managing internal service requests (IT support, hardware, software access, HR, finance, facility issues). Built with **Python FastAPI** and **PostgreSQL**.

---

## 🏢 Business Scenario

An organization where employees can raise internal service requests such as:
- IT support
- Hardware requests
- Software access
- HR requests
- Finance queries
- Facility issues

Different departments can receive, assign, process, and close requests through a centralized backend API.

---
